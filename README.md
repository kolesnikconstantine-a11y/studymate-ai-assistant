**StudyMate** — інтелектуальний AI-помічник для старшокласників, абітурієнтів та студентів, створений для підготовки з **математики, фізики та хімії**. Асистент побудований на базі **LangChain** із жорсткою прив'язкою до перевірених баз знань (JSON), детермінованих інструментів (`@tool`), мультимодального розбору задач за фото та відмовостійкого перемикання між моделями (**Google Gemini → OpenAI**).

---

## Ключові можливості

* **Пошук перевірених формул (`formula_lookup`)** — пошук у базі з **500 формул** (математика — 173, фізика — 175, хімія — 152) зі стемінгом основ слів, ранжуванням кандидатів, розшифровкою кожної змінної та числовим прикладом.
* **Конвертер фізичних величин (`unit_converter_physics`)** — переведення одиниць вимірювання у систему **СІ** за **28 напрямками** (швидкість, температура, енергія, тиск, маса, довжина, час) із розпізнаванням синонімів та скорочень.
* **Довідник таблиці Менделєєва (`periodic_table`)** — повна інформація про всі **118 хімічних елементів** за символом, українською або англійською назвою (атомний номер, молярна маса, група, електронна конфігурація, застосування).
* **Планувальник підготовки до іспитів (`study_planner`)** — оцінка годинного балансу (резерв або дефіцит часу) з урахуванням складності тем, валідацією реалістичності навантаження (≤ 16 год/день) та розрахунком сесій Помодоро.
* **Розбір задач за фото (`/photo`)** — завантаження зображень (`JPG`/`PNG`) у високій деталізації (`Base64`), виділення «Дано» та «Знайти», переведення величин у СІ та покрокове пояснення розв'язання.
* **Контекстна пам'ять діалогу та Guardrails** — підтримка уточнювальних запитів у межах сесії (`messages`), захист від «галюцинацій» (заборона вигадувати формули поза базою) та фокус виключно на освітніх задачах.

```text
   ├── Пріоритет 1: gemini-4-hydrogen (Google GenAI · Vision · max_output_tokens=1600)
   └── Резерв (Fallback): gpt-6-luna (OpenAI · Vision · max_tokens=1600 · timeout=30s)
        │
        ▼
Інструменти (@tool)
   ├── formula_lookup(query)          ──► FORMULAS_DB (500 формул)
   ├── unit_converter_physics()       ──► conversions{} (28 пар одиниць СІ)
   ├── periodic_table(query)          ──► PERIODIC_TABLE (118 елементів)
   └── study_planner(query)           ──► Детермінований розрахунок балансу годин
```

### Особливості реалізації
1. **Автономне завантаження баз даних (`load_json`)** — під час запуску система перевіряє локальний кеш JSON-файлів, а за їх відсутності автоматично завантажує актуальні бази за прямими посиланнями.
2. **Відмовостійкість (`invoke_with_fallback`)** — у разі помилки API, таймауту або порожньої відповіді від основної моделі (`gemini-4-hydrogen`) запит автоматично перенаправляється на резервну (`gpt-6-luna`). Для перевірки сценарію збою передбачено перемикач `SIMULATE_PRIMARY_FAILURE`.
3. **Антигалюцинаційний контроль** — `SYSTEM_PROMPT` забороняє моделі генерувати формули «з голови». Якщо формула відсутня у базі знань, асистент чесно повідомляє про це замість вигадування.

## Швидкий старт (Google Colab)

1. Відкрийте записник [`Final_Колісник_Костянтин_Анатолійович.ipynb`](https://colab.research.google.com/drive/1wQTVbLFwLDMI7WdFTb4IPFCOOp-VR2pi) у [Google Colab](https://colab.research.google.com).
2. Додайте API-ключі у вкладку **Secrets** (іконка ключа на лівій панелі Colab):
   * `GOOGLE_API_KEY` — ключ для Google Gemini (`gemini-4-hydrogen`);
   * `OPENAI_API_KEY` — ключ для резервної моделі OpenAI (`gpt-6-luna`).
3. Запустіть усі комірки послідовно (**Середовище виконання → Виконати всі**).
4. Для інтерактивного спілкування викличте `run_studymate_session()` та використовуйте команди:
   * звичайний текстовий запит (наприклад: *«Яка формула кінетичної енергії?»*);
   * `/photo` — завантажити фото умови задачі для розбору;
   * `/reset` — очистити історію поточного діалогу;
   * `exit` — завершити сесію.

## Валідація та тестування

У записнику реалізовано набір із **9 автоматичних тестів** (`run_automatic_tests()`), які перевіряють усі ключові сценарії роботи агента:

| № | Сценарій / Інструмент | Тестовий запит | Очікуваний та фактичний результат |
| :-: | :--- | :--- | :--- |
| **1** | Базовий діалог (без tool) | *«Привіт! Що ти вмієш?»* | Структурований перелік 5 можливостей українською |
| **2** | `formula_lookup` | *«Яка формула кінетичної енергії?»* | Знайдено $E_k = \frac{mv^2}{2}$, пояснено змінні та наведено приклад |
| **3** | Контекстна пам'ять | *«Поясни цю формулу простіше»* | Спрощене пояснення з опорою на попередню репліку |
| **4** | `unit_converter_physics` | *«Переведи 100 км/год у м/с»* | Точна конвертація `27.78 м/с` із кроком ділення на `3.6` |
| **5** | `periodic_table` | *«Розкажи про елемент Fe»* | Картка Феруму (№26, `55.845 г/моль`, властивості та застосування) |
| **6** | `study_planner` | *«15 тем, 10 днів, 3 год/день»* | Баланс годин: потрібно `22.5 год`, доступно `30.0 год` (резерв `7.5 год`) |
| **7** | Уточнення контексту | *«А чи вистачить часу за 7 днів?»* | Відновлення параметрів із `messages` та попередження про дефіцит `1.5 год` |
| **8** | Межі бази знань | *«Формула квантової заплутаності»* | Чесна відповідь про відсутність формули в базі без галюцинацій |
| **9** | Guardrail (межі ролі) | *«Порекомендуй фільм на вечір»* | Ввічлива відмова через спеціалізацію на точних науках |
